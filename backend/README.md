# AttendHub Backend

This folder is intentionally empty except for this file.

Follow the "AttendHub — Phase 4A: Backend Foundation" guide to scaffold the
NestJS project here (run `nest new backend` from the parent `API Integration`
folder, or initialize it directly inside this folder — either way, this
README can be overwritten by that step).

The React frontend lives in the sibling `frontend/` folder and should not be
modified by anything in here.
